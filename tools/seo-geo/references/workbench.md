# BeatGEO 本地操作工作台

## 打开页面

在项目目录运行：

```sh
pnpm start
```

浏览器打开启动输出的地址，默认 http://127.0.0.1:4317 。关闭终端服务后页面无法继续查询；已保存报告仍在本地。端口占用时可用 `BEAT_GEO_UI_PORT=4318 pnpm start`。

## 第一次使用

1. **连接设置**：输入 BeatAPI API Key，点击“保存连接”。默认只保留在服务内存；可选择“在本机记住 Key”。保存不验证远程权限/余额，也不产生查询费用。
2. **分析工作台**：填写自己的网站、市场，可添加竞品和关键词。勾选想了解的范围。
3. **预览分析与费用**：查看具体端点、域名、请求数和预计最高费用。预算不足时不能执行。
4. **确认费用并执行**：服务端才向 BeatAPI 发起请求。结果逐步保存；“停止后续查询”会等待当前请求结束，不会撤销已经发生的费用。
5. **报告与历史**：查看结果、打开完整报告、下载 Markdown 或 JSON 快照；重新打开不重复计费。“重新分析”会重新预览，确认后作为新查询计费。

不想输入 Key 时，点击“体验示例报告”查看合成数据；不会调用 BeatAPI。

## 六组选择覆盖十二个端点

- 网站概览：搜索概览、DR、站点流量。
- 竞品与内容：搜索竞品、排名词、热门页面。
- 主题与关键词：关键词拓展和概览，已包含难度。
- 外链研究：外链概况、外链列表。
- DR 历史：月度评分。
- 仅查询难度：单独的批量难度接口。

“全部能力”会勾选全部六组；需要关键词。日常可只选择必要能力，避免重复查询难度。

“更多设置”可调整返回行数、流量历史月数、预算、额外引用域名和其他市场代码。精确查询模式可单独选择十二个端点之一，设置目标域名、排名关键词子串筛选、分页 offset 和外链去重。额外参数仅在对应端点使用。国家/语言覆盖以接口为准，不支持中国大陆 `cn`。

## 与 GEO 连起来

在报告中选择“导入 AI 回答记录”，上传该项目原有 `records` 目录内的 JSON，可多选；也支持 `beat-geo/capture@1` 浏览器采集文件。不要上传 `summary.json`。本次导入会替换该报告之前关联的回答集，统计不会重复累加。

导入后可看到域名被 AI 引用的回答数/采样数。点击域名旁的“研究”，会为该域名预览三个查询：搜索概览、排名关键词、热门页面。确认后生成新报告，并保留原报告同站点的 GEO 背景。

网页不会自动运行 AI 模型。实际 GEO 多模型采样仍通过已有 CLI；网页负责 SEO 查询、导入已有回答、联合研究和整理问题。

## 内容任务与问题

“内容与问题”展示选定报告的研究建议；可将状态设置为待研究、进行中、已完成。任务不是自动发布指令。

候选问题可编辑、勾选，然后“保存已选问题”并下载 `questions.json`，供现有 GEO CLI 使用。保存为该报告独立的问题文件，不修改导入回答原来的问题文本，也不产生模型调用。再次保存会替换该报告导出的候选问题集；已运行的 GEO 原问题集不变。

## 导入和比较

- “导入 SEO 快照”接受 `beat-geo/seo-snapshot@1`，也就是 CLI 输出的 `seo-input.json`。保留合成标记，不重新查询。
- 选择同站点、同数据类型的历史报告，可“比较变化”。只比较查询参数一致且两边都有记录的指标。分页中的新出现/消失不判定为排名获得/丢失。
- 报告列表最多展示最近 100 次；输出文件仍保留在磁盘。

## 数据与 Key 保存位置

- 项目表单、查询记录、报告、任务和问题：项目下 `runs/workbench/`，已在 Git 忽略目录中。
- 默认 Key：仅服务进程内存，服务停止后清除；也可读取启动进程的 `BEATAPI_API_KEY`。
- 勾选记住 Key：`~/.beat-geo/workbench-key.json`，权限 600。是私有文件存储，不宣称加密保险库。报告导出不会包含 Key。
- 解除连接：清除内存与该工作台的私有文件，不撤销 BeatAPI 平台 Key。如果启动终端仍有环境变量，重启服务会再次读取它。
- 原 CLI 的命名 Key 来源绑定仍可用，工作台的可选 Key 文件与其分开。

服务只监听 127.0.0.1，不开放局域网或公网。Host、Origin、跨站访问校验及每次启动的新请求令牌用于保护本地操作。不要给这个单用户工作台添加公网隧道；团队线上版需要另行设计认证与隔离。

## 实测边界

开发验收使用合成数据和注入的模拟 HTTP，未调用真实收费接口。网页的执行链路、进度、持久化、重复执行拦截、取消及报告展示经过测试；真实 Key 权限、数据质量及实际账单仍需授权后做小额实测。
