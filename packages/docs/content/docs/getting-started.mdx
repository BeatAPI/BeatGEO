## Prerequisites

Prepare Git, Node.js 24, pnpm 12.4.1 and Chrome. PostgreSQL is bundled and managed by BeatGEO. No container runtime, separate database installation or paid API key is needed to open the workspace.

## Install and Start

```sh
git clone https://github.com/BeatAPI/BeatGEO.git
cd BeatGEO
pnpm local:setup
pnpm local:start
```

Open **http://localhost:3140/** to enter the workspace directly, without registration, login or a password. Add a website and use Connections (`/setup`) to load the bundled BeatBrowser extension into Chrome. Use the Chrome profile signed in to ChatGPT for real browser collection.

`local:setup` installs the locked dependencies, generates private credentials, initializes dedicated local storage and prepares the browser extension. It will not overwrite existing configuration. If an automatic setup was interrupted, run `pnpm local:setup --resume`.

Run `pnpm local:doctor` to check prerequisites without changing data. The private source CLI provides the same operations through `pnpm beatgeo doctor`, `pnpm beatgeo init` and `pnpm beatgeo start`; no globally published CLI is required.

## System Architecture

The web app, collector and worker run locally. PostgreSQL stores accounts, questions, results and scheduled jobs in `.beat-geo/postgres`. BeatBrowser uses your logged-in Chrome profile to collect answers and citations. Optional research providers support website research and Opportunities analysis.

Keep the start terminal, Chrome and the computer running for scheduled monitoring. Ctrl+C stops the local processes and saves storage. Restart with `pnpm local:start`; do not run setup again to reopen an existing workspace.

## Back Up Your Workspace

Stop BeatGEO before backing up `.beat-geo/postgres`, `.beat-geo/database.json`, root `.env` and `apps/web/.env` together. Keep these files private. Existing databases from older installations are never converted automatically.

For advanced configuration and existing installations, see the [self-hosting guide](https://github.com/BeatAPI/BeatGEO/blob/main/docs/self-hosting.md).
