## Prerequisites

- **Docker** — Docker Engine 24+ with Docker Compose v2
- **Node.js** — 18.x or later (for the CLI)
- At least one AI provider API key (OpenAI, Anthropic, or OpenRouter)
- **(Recommended)** A scraping provider to track the real ChatGPT and Google AI Mode experiences — see [Providers](/docs/user-guide/providers)

## Install the CLI

```bash
npm install -g @beatapi/geo-cli
```

## Initialize Your Instance

Run the interactive setup wizard:

```bash
beatgeo init
```

The wizard walks you through:

1. **Config directory** — Where to store your `beatgeo.yaml` and `.env` files (default: `./beatgeo`)
2. **PostgreSQL** — Run Postgres in Docker (recommended) or provide an existing `DATABASE_URL`
3. **AI Providers** — Configure scrapers ([Cloro](https://cloro.dev?fpr=beatgeo&fp_sid=docs), [BrightData](https://get.brightdata.com/beatgeo?sid=docs), [Oxylabs](https://oxylabs.go2cloud.org/aff_c?offer_id=7&aff_id=2263&url_id=32), [SearchApi](https://www.searchapi.io/?via=beatgeo), [Olostep](https://olostep.com/?ref=beatgeo), [DataForSEO](https://try.dataforseo.com/beatgeo)) and/or direct model APIs (OpenAI, Anthropic, Mistral, OpenRouter); see [Providers](/docs/user-guide/providers) for details
4. **Access** — Use BeatGeo on this machine (localhost), or from a domain behind a reverse proxy (see [Serving BeatGeo from a Domain](/docs/developer-guide/configuration#serving-beatgeo-from-a-domain))
5. **Start** — Optionally start the stack immediately

Once complete, BeatGeo generates two files in your config directory:

| File | Purpose |
|------|---------|
| `beatgeo.yaml` | Docker Compose configuration for all services |
| `.env` | Environment variables, secrets, and API keys |

## Start BeatGeo

If you didn't start during init, bring everything up with:

```bash
beatgeo compose up -d
```

This pulls the Docker images and starts all services. Once they report healthy, open **http://localhost:1515** in your browser.

## System Architecture

<img
  src="/brand/architecture.svg"
  alt="BeatGeo system architecture: User connects to Web; Web and Worker share a Postgres database; Web calls LLM APIs; Worker calls both LLM APIs and an LLM Scraper."
  className="my-6 w-full"
/>

| Service | Role |
|---------|------|
| **Web** | Dashboard UI and REST API |
| **Worker** | Background scheduler that drives prompt runs |
| **Postgres** | Shared database and job queue |
| **LLM APIs** | Direct API calls (OpenAI, Anthropic, OpenRouter) |
| **LLM Scraper** | Scrapers for ChatGPT, Google AI Mode, and other live AI surfaces ([Cloro](https://cloro.dev?fpr=beatgeo&fp_sid=docs), [BrightData](https://get.brightdata.com/beatgeo?sid=docs), [Oxylabs](https://oxylabs.go2cloud.org/aff_c?offer_id=7&aff_id=2263&url_id=32), [SearchApi](https://www.searchapi.io/?via=beatgeo), [Olostep](https://olostep.com/?ref=beatgeo), [DataForSEO](https://try.dataforseo.com/beatgeo)) |
| **BeatGeo CLI** | Generates `beatgeo.yaml` + `.env` and runs `docker compose` |

## CLI Commands Reference

Once BeatGeo is running, these commands help you manage it:

```bash
# View live logs
beatgeo compose logs -f

# View logs for a specific service
beatgeo compose logs -f web

# Check service status
beatgeo compose ps

# Stop all services
beatgeo compose down
```
