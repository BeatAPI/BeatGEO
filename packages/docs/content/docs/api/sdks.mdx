---
title: SDKs
description: Call the BeatGeo API from TypeScript or Python.
---

BeatGeo publishes typed clients for the [REST API](/docs/api), generated from the same OpenAPI spec the
API serves, so a new endpoint reaches them without anyone writing it by hand.

| Language | Package | Source |
| --- | --- | --- |
| TypeScript | [`@beatapi/geo-sdk`](https://www.npmjs.com/package/@beatapi/geo-sdk) | [beatapi/beat-geo-sdk-typescript](https://github.com/BeatAPI/BeatGeo-sdk-typescript) |
| Python | [`beatgeo-sdk`](https://pypi.org/project/beatgeo-sdk/) | [beatapi/beat-geo-sdk-python](https://github.com/BeatAPI/BeatGeo-sdk-python) |

Both read an [API key](/docs/api#authentication) from `BEAT_GEO_API_KEY` and the address to call from
`BEAT_GEO_BASE_URL`. The base URL has no default you can rely on — every instance serves the API on its own
address — so always set it. On cloud that is `https://github.com/BeatAPI/BeatGeo`; a self-hosted instance
uses its own `APP_URL` followed by `/api/v1`.

```bash
export BEAT_GEO_API_KEY=beatgeo_...
export BEAT_GEO_BASE_URL=https://github.com/BeatAPI/BeatGeo
```

Every deployment also shows both snippets at **Settings → API**, with its own base URL filled in.

## TypeScript

```bash
npm install @beatapi/geo-sdk
```

```ts
import { BeatGeo } from "@beatapi/geo-sdk";

const beatgeo = new BeatGeo();

for await (const brand of beatgeo.brands.list()) {
  console.log(brand.name);
}
```

Pass `apiKey` and `baseURL` to the constructor instead of setting the environment variables, for
example to talk to two instances from one process. Node.js 20.19 or later is required.

## Python

```bash
pip install beatgeo-sdk
```

```python
from beatgeo_sdk import BeatGeo

beatgeo = BeatGeo()

for brand in beatgeo.brands.list():
    print(brand.name)
```

`AsyncBeatGeo` has the same calls for `asyncio`. Pass `api_key` and `base_url` to the constructor instead of
setting the environment variables. Python 3.10 or later is required.

## Versions

Each SDK is versioned on its own, by what changed in the API rather than by BeatGeo's release number: a
removed or changed endpoint is a major version, a new one a minor version. Each repository's README
covers pagination, errors, retries, and timeouts in full.
