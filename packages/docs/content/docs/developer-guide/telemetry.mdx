---
title: Telemetry
description: Local telemetry defaults and privacy controls.
---

The local installer sets `DISABLE_TELEMETRY=1` in both private environment files. The source CLI runs local scripts without a newsletter signup or telemetry setup wizard.

Keep `DISABLE_TELEMETRY=1` in root `.env` and `apps/web/.env`. Stop the launcher with Ctrl+C and restart with `pnpm local:start` after changing environment settings.

Raw browser evidence, local database files and credentials stay in ignored workspace directories. Do not commit them. For the local data boundaries, see the [privacy guide](https://github.com/BeatAPI/BeatGEO/blob/main/docs/privacy.md).
