## Prerequisites

Use Git, Node.js 24, pnpm 12.4.1 and Chrome. The source installer bundles PostgreSQL and the browser extension.

```sh
git clone https://github.com/BeatAPI/BeatGEO.git
cd BeatGEO
pnpm local:doctor
pnpm local:setup
pnpm local:start
```

Open http://localhost:3140/. Local mode opens the workspace without registration or login. The launcher runs the web app, browser collector, worker and dedicated database together. Ctrl+C stops them. Vite reloads source changes during development.

## Configuration

Setup creates root `.env` and `apps/web/.env` with matching local credentials. Keep both files private and synchronized. Use Connections in the app for optional research credentials. Browser collection uses the Chrome account selected through BeatBrowser; direct API calls and synthetic fixtures are separate from real browser evidence.

An interrupted setup can be resumed with `pnpm local:setup --resume`. Existing configuration is never overwritten or converted automatically. Back up local storage and credentials before changing database settings.

## Component Stories

```sh
pnpm --filter @workspace/web storybook
```

Stories live in `apps/web/src/stories/`. For checks and isolated regression, see [Commands Reference](/docs/developer-guide/commands).
