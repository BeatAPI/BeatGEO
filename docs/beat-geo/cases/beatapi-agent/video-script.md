## 录制顺序与证据页

1. 录制工作台 `recording-workbench.html`：稳定解释与结果摘要。浏览器打开后用方向键或章节按钮切换，空格控制计时，F 全屏；画面是准备好的讲解稿。
2. BeatGEO 本地「真实案例」：逐步回顾与摘要下载，不实时采集。
3. 已授权的本地 BeatAPI 项目：回答与草稿证据。只打开与本次任务有关的页面，录制时遮挡账号区域。
