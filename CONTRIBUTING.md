# Contributing to BeatGEO

Use a branch and pull request against main. Follow AGENTS.md, retain third-party notices, and keep credentials or raw customer/browser evidence out of Git. Use Node.js 24 and pnpm 12.4.1. Run lint and affected tests; distinguish mocked checks from real provider validation.

No upstream CLA or commercial service enrollment is required. Contributions are provided under this repository's MIT license.
